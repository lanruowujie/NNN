# NNN 文档索引

NNN 是用于**获得授权的 NFC/卡片读写安全测试**的 GUI 工作台。文档描述系统边界、运行机理、验证方式和实施记录；真实环境测试必须使用明确授权的卡片、读卡器和系统。

## 核心数据流

```text
GUI
  → Wails bindings
    → 应用服务
      → 设备/Reader 抽象或离线虚拟卡实验室
        → 可取消 task
          → nfcx:task 事件
            → 进度条、活动日志、结构化结果
```

读写任务必须经过状态检查、结构校验、认证、写入保护和回读验证；长任务不能阻塞 GUI。真实硬件测试不能由普通离线测试自动触发。

## 虚拟卡实验室

`tools/virtual_lab/` 是无硬件、无网络的合成卡实验。它提供固定上限的受限审计、静态克隆检测、实时进度和日志事件，用于观察弱密钥、动态认证、计数器和防克隆逻辑。

```bash
python3 -m unittest -v tools/virtual_lab/test_virtual_card_lab.py
python3 tools/virtual_lab/virtual_card_lab.py --demo
```

## 通用完成定义

每项改造都应满足：自动化测试通过；文档与实际行为一致；不提交真实卡片密钥或生产数据；普通测试不要求连接读卡器；GUI 长任务可取消并显示状态；第三方依赖记录来源和许可证。

## 责任边界

NNN 不是授权绕过工具。禁止将它用于未授权访问、凭证复制、第三方系统克隆或超出书面范围的测试。发现测试超出授权范围时应立即停止并保存脱敏证据。
