# 24. 一键虚拟卡实验入口

## 已完成

在不改变 NNN 原有读卡、写卡、dump、密钥管理和既有工作流的前提下，为离线虚拟卡实验室增加两个命令入口：

- `--crack`：对程序内置合成卡执行固定候选的受限口令审计，最多 64 次尝试；
- `--clone`：在内存中复制静态快照并立即运行克隆检测。

## 安全边界

两个入口都只创建新的 `VirtualCard` 对象，不接收读卡器、真实卡片、真实 dump、网络地址或外部命令参数。`--clone` 生成的是没有动态认证秘密的教学静态克隆，因此预期结果是静态字段冲突但动态认证失败；它不会生成可写入实体卡的副本。

## 验证

- Python 标准测试：7 项全部通过。
- `python3 tools/virtual_lab/virtual_card_lab.py --crack`：第 3 次候选命中合成测试口令。
- `python3 tools/virtual_lab/virtual_card_lab.py --clone`：检测到 UID/静态指纹冲突，克隆动态认证被拒绝。

无。
