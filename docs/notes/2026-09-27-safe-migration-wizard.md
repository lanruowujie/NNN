# 安全迁移向导

## 已完成

- 增加中英文“安全迁移向导”入口。
- 向导复用已有的已知密钥读取、dump 完整性检查、写入预检、逐块回读验证流程。
- 向导明确要求先读取源卡，再更换目标实体卡；默认不写 UID、不修改源卡。
- 文案明确未知密钥恢复和手机钱包写入不属于此向导。

## 问题与阻塞

无。真实硬件验证仍需在用户自有 PN532 和兼容实体卡上显式进行。

## 密钥库便捷流程

- 密钥库继续使用现有本地持久化 JSON 存储；手动输入和字典导入都会自动保存。
- 新增“验证密钥库”按钮，按密钥库顺序对当前卡片执行授权认证。
- 没有任何成功认证时，界面自动打开密钥库并聚焦输入框，提示继续输入并再次验证。
- 成功认证的密钥由现有后端记录为当前卡片的已验证上下文，可供后续读取和安全写入使用。
