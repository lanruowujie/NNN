# 25. 虚拟卡实验实时进度与日志

## 已完成

虚拟卡一键受限审计和一键克隆检测已从同步调用改为复用 NNN 既有的异步 operation/task 管线。后端通过 `startOperation` 创建可取消任务，并通过 `nfcx:task` 连续发送 `started`、`progress`、`completed` 或 `cancelled` 事件。

审计任务按候选口令发送阶段事件，包含当前尝试数、百分比和日志消息；克隆检测任务按静态快照复制、指纹比对、计数器检查和动态认证四个阶段发送事件。前端复用主任务区的进度条、活动日志、任务状态和取消按钮，并在虚拟卡实验室面板实时刷新最后一次实验结果。

## 使用方式

在 GUI 左侧的“虚拟卡实验室”区域点击“一键受限审计”或“一键克隆检测”。进度显示在主窗口活动区的进度条，过程日志显示在活动日志列表，任务运行时可通过主任务区的“取消”按钮停止。

## 安全边界

任务只针对程序内置合成虚拟卡，不接收读卡器、真实卡片、真实 dump、网络地址或用户字典；不会调用 libnfc 或外部破解工具。
