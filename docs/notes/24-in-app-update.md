# 24 — 低打扰应用内更新实施记录

完成内容：替换 About 页面中依赖普通 HTML 链接的更新入口，新增与顶部栏融合的更新状态胶囊、About 更新卡片、后台下载动作和“自动下载稳定版更新”偏好。启动后的检查以 24 小时为节流周期在后台进行，不弹出模态窗口；手动检查仍可随时进行。

新增 `internal/update`：严格的 SemVer 比较、GitHub Release 元数据校验、HTTPS asset 约束、SHA-256 流式校验、0700 私有 staging 目录和 0600 本地状态文件。更新检查不使用遥测 installation ID，也不访问 NFC 读卡器。存在 NFC 任务或未保存工作副本时，重启更新动作会被拒绝。

后续调整：默认更新源改为 GitHub Releases API。客户端只接受最新的正式 Release、精确匹配当前平台的 asset 与 API 返回的 SHA-256 digest，并在下载后复算 hash；这使普通构建默认可以检查更新，不再要求额外更新服务或密钥配置。

阻塞或未完成事项：仍需按规格 16 将平台 updater 打包、签名和接入安全退出/回滚流程；即使下载资产已验证，当前构建也不会假装可以替换正在运行的应用。无其他阻塞。
