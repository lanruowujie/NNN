# 规格 04 自动化验收证据：设备管理与寻卡

日期：2026-09-12  
平台：macOS arm64  
libnfc：固定版本 1.8.0，`pn532_uart` 驱动

## 自动化验收

以下检查通过：

```sh
go test ./...
go test -race ./internal/device/... ./internal/nfc/... ./app/...
go vet ./...
make frontend-build
make libnfc-binding-test
```

自动化测试覆盖：

- DeviceManager 对轮询和并发操作的串行化；
- 相同卡片事件去重；
- 卡片移除防抖以及换卡时的移除/出现顺序；
- 设备断开后的错误、恢复、成功重连及有限失败次数；
- 权限错误不进入重连循环；
- context 取消后轮询调用和 goroutine 退出；
- 手动 connstring 原样传入首次连接及每次恢复；
- 设备枚举去重但不改写 connstring；
- UID 长度和保守卡型推断的 DTO 序列化；
- C shim 设备名称复制接口能够使用固定 libnfc SDK 编译。
- 应用启动会为缺失的自动扫描/侵入式扫描选项设置进程内默认值，并保留用户显式环境配置。
- 连接控件在连接、已连接、恢复和断开状态间使用单一按钮切换，避免已连接后再次发起连接。
